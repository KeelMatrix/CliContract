# Privacy

KeelMatrix CliContract processes command-line schema files locally. After a successful comparison with a nonempty baseline, version 0.1 requests one best-effort activation through the published `KeelMatrix.Telemetry` package. The request passes no schema-derived values. The shared contract may emit an activation event, telemetry schema version, anonymous project and installation hashes, a generic tool label, tool version, runtime/platform, CI indicator, and timestamp; it does not receive command names, options, aliases, descriptions, defaults, accepted values, schema contents, baseline contents, repository names, paths, or diagnostics. The tool does not execute the described CLI or fetch remote references. Schema parsing and comparison do not need a network connection; the optional activation request is the only network behavior.

The tool reads only paths supplied to its commands and writes a snapshot only when `snapshot --output` succeeds. Diagnostics use stable codes and logical paths; they do not echo complete schemas, descriptions, defaults, credentials, repository names, or filesystem paths.

`--no-telemetry`, `KEELMATRIX_NO_TELEMETRY=1`, `KEELMATRIX_DEVELOPMENT=true`, and `CI=true` disable the activation request. There is no periodic heartbeat. Any telemetry construction or delivery failure is swallowed so it cannot affect tool behavior. See [`KeelMatrix.Telemetry`](https://github.com/KeelMatrix/Telemetry) for the canonical shared field and retention policy.
